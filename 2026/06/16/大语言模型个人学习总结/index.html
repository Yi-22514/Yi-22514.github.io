大语言模型个人学习总结

学习 Happy-LLM 第四章时，我最大的感受是：大语言模型并不是“更大的聊天机器人”，而是预训练语言模型在模型规模、数据规模、训练流程和使用方式上共同演化出来的新阶段。

如果说 BERT、GPT 这类 PLM 证明了“预训练 + 微调”是有效的，那么 LLM 则进一步证明了：当参数量、训练数据和计算量扩大到一定程度后，模型会出现一些传统小模型很难具备的能力，比如上下文学习、复杂指令理解、多步推理和较强的开放式生成。

一、什么是大语言模型

我现在对 LLM 的理解可以概括成三点：

  1. 它通常有更大的参数量和更大的预训练语料。
  2. 它主要通过自监督学习从海量文本中学习语言规律。
  3. 它不仅能完成单一 NLP 任务，还能通过 Prompt 适配多种任务。

大语言模型和传统预训练模型之间不是完全割裂的关系。LLM 可以看作是 PLM 的扩展，但它不只是“参数变多”。真正重要的是，模型的使用方式也变了。以前我们习惯为每个任务准备数据并微调模型，现在则可以通过提示词、示例和上下文直接引导模型完成任务。

这也是为什么 LLM 时代的核心能力不再只是“模型会不会分类”，而是“模型能不能理解指令、利用上下文、组织答案并完成复杂任务”。

二、训练 LLM 的三个阶段

一个完整的大语言模型通常会经历三个主要阶段：Pretrain、SFT 和偏好对齐。

Pretrain 是最基础也是成本最高的阶段。模型在海量无监督文本上训练，目标通常是因果语言模型，也就是根据上文预测下一个 token。这个阶段让模型获得通用语言能力和大量世界知识。

SFT 是有监督微调。它使用人工构造或筛选的指令数据，让模型学习如何按照用户意图回答问题。预训练模型可能会续写文本，但不一定会“听指令”；SFT 的意义就是把模型从“语言续写器”调整成“指令响应器”。

偏好对齐 则是让模型输出更符合人类偏好的回答。传统路线中常见的是 RLHF，也就是基于人类反馈的强化学习。现在也有 DPO 等更简洁的偏好优化方法。对我来说，对齐阶段解决的不是模型“会不会说”，而是模型“该怎么说、什么不该说、怎样更有帮助”。

三、涌现能力带来的理解变化

LLM 中很重要的一个概念是涌现能力。它指的是当模型规模达到某个阶段后，模型突然表现出一些小模型没有的能力，比如少样本学习、指令跟随、多步推理等。

这让我想到一个很有意思的点：模型能力并不是线性增长的。参数量增加一点，不一定马上能看到明显变化；但当数据、参数和计算量一起跨过某些门槛时，模型可能会表现出新的能力。

不过我也觉得，涌现能力不能被理解成玄学。它背后仍然和训练目标、数据分布、模型结构、评测任务有关。所谓“突然出现”，很多时候可能是指标超过某个可见阈值后才被我们观察到。

四、Scaling Law 的启发

Scaling Law 是这一章里很关键的思想。它试图描述模型参数量、训练数据量和计算量之间的关系。一个常见的计算量近似可以写成：

$$C \approx 6ND$$

其中 $C$ 表示训练计算量，$N$ 是模型参数量，$D$ 是训练 token 数。

这个公式给我的启发是：训练 LLM 不能只盯着参数量。一个模型如果参数很大，但训练数据不够，可能会欠训练；如果数据很多但模型太小，也可能无法充分吸收信息。真正的问题是如何在算力预算下平衡参数、数据和训练步数。

从 GPT-3 到 LLaMA，再到后来的各种开源模型，一个明显趋势是大家越来越重视数据质量和 token 数。更大的模型不一定永远更优，数据配比、清洗质量和训练效率同样重要。

五、LLM 和传统 PLM 的区别

我会从下面几个角度区分 LLM 和传统 PLM：

  • 任务形式不同：PLM 更多依赖下游微调，LLM 更多依赖 Prompt 和指令。
  • 架构路线不同：当前主流 LLM 基本采用 Decoder-only 架构。
  • 能力边界不同：LLM 更强调开放生成、上下文学习和多任务泛化。
  • 训练成本不同：LLM 的预训练需要巨大的数据、算力和工程系统。
  • 应用方式不同：LLM 往往作为通用能力底座，被接入 RAG、Agent、工具调用等系统。

这也解释了为什么现在很多应用不是单独训练一个任务模型，而是围绕 LLM 构建上下文、工具和工作流。

六、我的阶段性理解

学完这一章之后，我对 LLM 的理解从“模型很大”变成了“规模化训练后的通用语言能力平台”。它的能力来自多个因素叠加：Transformer 架构、Decoder-only 自回归目标、大规模高质量语料、合理的 Scaling 策略、指令微调以及人类偏好对齐。

LLM 的强大也不意味着它没有边界。它仍然可能幻觉、可能过时、可能推理失败，也可能在特定领域不如小而专的模型。所以后面学习 RAG、Agent、微调和评测时，核心问题其实都是：如何把 LLM 的通用能力稳定地接到真实任务里。

这章对我来说像是一个分水岭：前面学的是模型结构，后面要开始理解训练工程和应用系统。真正的大模型能力，不只存在于参数里，也存在于数据、训练流程、对齐方法和应用架构里。
